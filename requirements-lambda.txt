# 2.9.12+는 arm64 wheel이 manylinux_2_27/2_28(glibc>=2.27)만 나와서, 이
# Lambda 베이스 이미지(Amazon Linux 2, glibc 2.26)에서 prebuilt wheel을
# 못 찾고 소스 빌드로 폴백한다 - 빌드는 되지만(pg_config만 있으면) 그
# libpq가 너무 오래돼서(9.2) 런타임에 undefined symbol: lo_truncate64로
# 죽는다(직접 재현 확인). 2.9.11까지는 manylinux2014(glibc>=2.17) wheel이
# 있어서 이 이미지에서 prebuilt wheel을 그대로 받는다 - 버전을 올리려면
# 먼저 로컬에서 `docker build --platform linux/arm64 -f docker/lambda/Dockerfile .`
# 로 빌드해서 실제 psycopg2 import가 되는지 확인할 것.
