# 09. Bronze GX 검증

## 문제
- 검증 실패를 종류 구분 없이 다 똑같이 처리
  - 전부 중단 → 사소한 노이즈에도 파이프라인 정지
  - 전부 통과 → 필수 컬럼 소실도 그냥 넘어감

## 원인
- "컬럼이 아예 없음(치명적)"과 "값만 이상함(경미)"이 섞여 있음
- 구분 안 하면 위 문제 중 하나가 반드시 발생

## 대안

| 방법 | 장점 | 단점 |
| --- | --- | --- |
| 전부 critical | 이상 즉시 차단 | 노이즈에도 정지 |
| 전부 log-only | 파이프라인 안 멈춤 | 치명적 문제도 조용히 통과 |
| 컬럼 존재=critical / 값 이상=log-only | 치명적 문제만 차단 | 도메인마다 기준 관리 필요 |

## 결정
- 컬럼 존재 여부 → critical
- 값 범위·결측 → log-only

## 도메인별 적용

| 도메인 | critical 기준 | critical 대응 | log-only 대응 |
| --- | --- | --- | --- |
| TLC | 필수 컬럼 존재 | 해당 파일만 제외, Slack 알림 | 로그만 (Slack 없음) |
| speed | 필수 컬럼 존재 | 이번 주기 스킵, Slack 알림 | 로그 + Slack |

## 남은 문제
- TLC는 log-only 실패가 Slack으로 안 감 → 사람이 못 알아챔
- speed는 log-only도 Slack 감 → TLC보다 나음
