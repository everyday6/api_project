# 03. EMR 자원 경합

## 문제
- DAG 3개가 EMR 자원(계정 전체 vCPU)을 공유
- 조율 없이 사용 → 하나가 독점, 나머지 굶음

## 원인
- Airflow "동시 실행 수 제한" ≠ 실제 EMR 자원 제한
- Spark 작업은 그 안에서 자원 무제한 확장 가능

## 대안

| 방법 | 장점 | 단점 |
| --- | --- | --- |
| 기존 유지 (Airflow 순번 관리만) | 단순 | 문제 그대로 |
| 계정 자원 증설 요청 | 코드 변경 불필요 | 근본 해결 안 됨, 비용 증가 |
| DAG별 자원 몫 고정 | 독점 방지 | 몫 배분을 수동 관리 |

## 결정
- DAG별로 쓸 수 있는 자원 몫을 고정 배분
